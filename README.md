## How to Run a Project

Clone the repository:

```bash
git clone https://github.com/ANMOL0me/python.git
```

Move into the repository:

```bash
cd python
```

Open the project you want to run:

```bash
cd Calculator
```

Run the Python file:

```bash
python main.py
```

The exact entry-point file may differ between projects, so check the individual project folder before running it.
